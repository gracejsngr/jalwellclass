# 잘될거야 우리 반 (Vercel 버전)

입장 코드를 아는 사람만 들어올 수 있는 3학년 5반 학급 사이트예요.

- **선생님 코드**: 모든 기능을 쓰고 모든 기록을 봐요.
- **반 코드(학생용)**: 교실 화면(학생 모드)으로만 열려요. 학생 이름, 시험 점수, 체험학습, 상담·건강·생활 기록, 선생님 비밀번호, 학생 코드는 **서버에서 빼고** 보내요. 학생이 바꿀 수 있는 건 예측·퀘스트·칭찬·과목 게시판·지각 체크뿐이에요.

## 폴더 구성

| 경로 | 하는 일 |
|---|---|
| `public/index.html` | 학급 사이트 화면 |
| `public/login.html` | 입장 코드 화면 |
| `middleware.js` | 코드를 넣지 않은 사람을 입장 화면으로 보냄 |
| `api/login.js` · `api/logout.js` | 코드 확인, 입장 쿠키 발급·삭제 |
| `api/db.js` | 기록 읽기·쓰기 (학생이면 걸러서) |
| `api/health.js` | 설정 점검 (`/api/health`) |

## 처음 설치 (한 번만)

1. **Vercel에 연결**: vercel.com → GitHub로 로그인 → *Add New → Project* → `jalwellclass` 저장소 *Import* → 설정은 그대로 두고 *Deploy*.
2. **저장소 연결**: 만든 프로젝트 → *Storage* 탭 → *Upstash* (Redis) 선택 → 무료 요금제로 만들고 이 프로젝트에 연결. 연결되면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 값이 자동으로 들어가요.
3. **비밀값 넣기**: *Settings → Environment Variables* 에 세 개를 추가해요.
   | 이름 | 값 |
   |---|---|
   | `TEACHER_CODE` | 선생님만 아는 코드 (8자리 이상 권장) |
   | `CLASS_CODE` | 학생들에게 알려 줄 반 코드 |
   | `SESSION_SECRET` | 아무 긴 글자 (40자 이상, 예: 비밀번호 생성기로 만든 값) |
4. *Deployments* → 가장 위 배포의 *⋯ → Redeploy* (비밀값을 반영하려면 한 번 다시 배포해야 해요).
5. 나온 주소(…vercel.app)로 들어가 **선생님 코드**로 입장.
6. **기존 기록 옮기기**: Claude에 있는 원래 사이트에서 설정 → *백업 저장*으로 파일을 받고, 새 사이트 설정 → *백업 불러오기*로 그 파일을 넣어요.

## 코드를 바꾸고 싶을 때

*Settings → Environment Variables* 에서 `CLASS_CODE`(또는 `TEACHER_CODE`)를 바꾸고 *Redeploy*. 모든 학생을 한꺼번에 내보내려면 `SESSION_SECRET`도 함께 바꿔요.

## 알아 둘 것

- 사진 올리기와 날씨는 이 버전에서 꺼져 있어요 (Claude 안에서만 되는 기능).
- 학생 화면의 *내 기록 보기*는 학생 코드가 서버에서 빠져 있어서 작동하지 않아요.
- 반 코드는 반 전체가 같이 쓰는 열쇠라, 누가 어떤 걸 눌렀는지 서버가 학생별로 구분하지 못해요.
- 같은 화면을 여러 명이 동시에 고치면 마지막 저장이 이겨요. 기록은 15초마다 새로 불러와요.
- 저장소 GitHub 저장소는 **Private**로 두세요. (코드에 학생 정보는 없지만 습관상 안전해요.)
